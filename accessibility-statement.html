Accessibility Statement

I want this website to be usable by as many people as possible, including people with disabilities. I aim to make the site conform to the Web Content Accessibility Guidelines (WCAG) 2.2 Level AA and beyond.

This site has been designed with accessibility in mind, and has undergone thorough testing to ensure it meets accessibility standards and best practices.

Feedback and assistance

If you encounter an accessibility barrier please message me on LinkedIn. Please describe the page and the issue you encountered so I can work to address it.
